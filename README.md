# Weather Icon Display

An interactive web application that displays weather icons and descriptions based on the condition selected from a dropdown menu. Built using HTML, CSS, and JavaScript with predefined static data.

## ✨ Features

- **Weather Selection:** Choose from different weather conditions.
- **Dynamic Icons:** Displays a matching icon for each condition.
- **Condition Descriptions:** Shows information about the selected weather.
- **Dynamic Backgrounds:** Updates the background style based on the selected condition.
- **Default State:** Displays an initial message before a selection is made.
- **Responsive Design:** Provides a user-friendly interface across devices.

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript

## 🚀 How to Run

1. Clone or download this repository.
2. Open the project folder in your code editor.
3. Open `index.html` in your browser.
4. Select a weather condition from the dropdown.
5. View the corresponding icon, description, and background style.
