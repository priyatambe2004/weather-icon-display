How it works

Every condition lives in one JavaScript object. The dropdown value is the key, so showing a condition is a single lookup.

const WEATHER = {
  sunny: { label: 'Sunny', icon: sunIcon, temp: 32 },
  rainy: { label: 'Rainy', icon: rainIcon, temp: 21 }
};

const data = WEATHER[select.value] ?? DEFAULT;
render(data);
  • Object, not if/else Adding a new condition means adding one entry. No new branches.
  • Default state An unknown or empty key falls back to DEFAULT, so the page is never blank.
  • CSS does the mood The script only sets data-weather on the page. The CSS picks the sky colours and effects.

The temperatures and other values are sample data, not a real forecast.
